# What is Debugging in Node.js?

---

Debugging means finding and fixing errors or problems in a Node.js application.

We can use `console.log()` or the VS Code debugger to check the code and find where the problem is.

## Example

    function add(a, b) {

      console.log(a, b);

      return a + b;
    }

    console.log(add(10, 20));

## Interview Answer

"Debugging means finding and fixing errors in Node.js code. We can use console.log() or the VS Code debugger to find and fix problems."
