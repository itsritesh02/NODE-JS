
# Node.js Modules

---

Modules are reusable pieces of code in Node.js.

There are 3 types:

1. Core Modules → Built into Node.js.
   Example: `fs`, `http`, `path`

2. Local Modules → Created by us.
   Example: `./math.js`

3. Third-Party Modules → Installed using npm.
   Example: `express`, `mongoose`, `dotenv`

## Interview Answer

"Node.js modules are reusable pieces of code. They are mainly of three types: Core, Local, and Third-Party modules."
